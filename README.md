# simple-play-simple

[日本語](./README_JP.md)

This repository is an extended and refined version of the skin originally created by mnpy-san.

## Extensions and Improvements
- Simplified logic from the original skin
- Added yellow number (represents the green number in milliseconds)
- Added a lane cover that follows BPM changes (enable with the skin option `FollowLaneCover`, then toggle it in play with CONSTANT; it moves while SUDDEN+ and HI-SPEED FIX are on)
